# T2 ACT-Rの成分診断

主結果を確認した後の探索的診断。主9モデル、主ラベルL=1、モデル期限29日/149日は変更していない。推薦から24時間以上〜90日後の自発再聴（C）、同じ967,884テストペア、AUC算出可能な4,124ユーザーで比較する。全版に学習ペアだけで推定した共通ヘッドを適用。

ACT-R−AudioCosineの対応付き差は−0.051342（95%区間−0.057052〜−0.045272）。各ユーザーのAUC差を1000回、ユーザー単位で再標本化した。

## 差を説明する観測

1. **Sの識別力が失われやすい。** 86.02%のテストペアで正規化後の対象Sが厳密に0。74.26%で直前曲の自己項がSのsoftmax質量の99%超を占める。自己liftはセッション数/文脈曲出現セッション数となり、希少曲で大きい。max shiftはoverflowを避けるがtailのunderflowは避けない。float32の早いゼロ化と、float64でも起こりうる極端なliftの影響は未分離。
2. **SをPへ足す上乗せは確認できない。** ACT-R−P-onlyは+0.000539（95%区間−0.002124〜+0.003345）。raw Sを同じ共通ヘッドへ入れた版はS-onlyを+0.016378（+0.012383〜+0.020264）上回る。ただしraw Sの学習係数は負であり、正の共起liftが正例へ単純に結びつくという意味ではない。
3. **直前1曲は長期organic嗜好平均と違う。** 直前文脈がorganicなのはテストペアの3.53%。Pはその直前1曲、AudioCosineは全過去organic再生の音響平均を使う。raw Pの共通ヘッド後AUCは0.502654（区間は0.5を含む）。P-only−raw Pの差も+0.007327（−0.000929〜+0.016253）であり、「Pのsoftmaxを外せば改善する」という仮説は支持されない。
4. **候補集合の大きさの影響がある。** 候補数だけの共通ヘッドは0.529804で、ACT-Rより+0.019284（+0.013218〜+0.024800）。正規化されたS/Pが履歴量・候補数の違いを強く含むことと整合するが、因果的な寄与率は測っていない。

## organicのみの版の向き

organic-SPは、organicイベントだけに絞ってから30分セッションを再構成し、直前organic曲・organic履歴候補＋対象曲でS/Pを計算する。T2にbase-levelは使わない。共聴・文脈・候補集合を同時に変更する診断であり、単一要因の効果ではない。

この版のrawスコアは、学習の全体AUC0.420585に対してユーザー内AUC0.529455。学習だけで推定したヘッドの係数は−0.370836。テストでもraw全体AUC0.454510、rawユーザー内AUC0.530608と向きが食い違い、負のヘッドがユーザー内順位を反転して0.469392となる。学習から既に全体とユーザー内で順位の向きが異なり、全体損失で学ぶヘッドとユーザー等重み評価の不一致と整合する。自発再生情報が無効と結論しない。テストを見て符号を反転したりヘッドを選び直したりしていない。

organic履歴がない場合は候補が対象曲だけで、各成分の一様softmaxが1、合計スコアが2となる。テストの58,625ペア（6.06%）が該当し、正例率3.30%。履歴ありの正例率10.04%、スコア中央値0.002443と比べ、高スコアかつ低正例率の集団がある。これは負の全体係数に寄与しうるが、唯一の原因とは確認していない。欠損規則は結果確認後に変更していない。

## 部分一致の埋め込み

Yambda embeddings.parquetのnormalized_embed列、128次元L2正規化済み音響CNNベクトル。AudioCosineと同一。元データはdouble、50Mキャッシュはfloat32。スペクトログラムに対するcontrastive学習とCLMRの参照は公式論文にあるが、正確なCNN構成・既成CLMR checkpointとの同一性は不明。協調因子や意味テキスト埋め込みは使っていない。詳細と一次資料は ../DECISIONS.md。
